# 英文票据OCR实体标注服务需求文档

## 1. 项目概述

### 1.1 项目目标
构建一个基于Label Studio的数据标注服务，用于处理2万张英文票据图片的OCR结果，进行实体识别和类别标注。

### 1.2 业务背景
- **数据来源**: 2万张英文票据图片
- **预处理状态**: 已通过OCR处理并生成包含掩码标记的文本
- **标注需求**: 识别未被`[MASK]`遮挡的实体并进行精确分类
- **应用场景**: 票据信息提取、实体识别模型训练

## 2. 功能需求

### 2.1 核心功能
1. **批量任务导入**: 支持2万个标注任务的批量导入
2. **实体识别标注**: 在预处理文本中标注未遮挡的实体
3. **类别分类**: 为识别的实体分配正确的类别标签
4. **结果导出**: 按指定格式导出标注结果

### 2.2 标注工作流程
```
输入文本 → 实体选择 → 类别分配 → 结果验证 → 提交标注
```

### 2.3 任务输入格式
每个标注任务包含：
- **标注指令**: 明确的任务说明和实体类别定义
- **OCR文本**: 包含`[MASK]`标记的预处理文本
- **期望输出**: 实体清单格式示例

## 3. 实体类别体系

### 3.1 主要类别 (4大类)
1. **人名相关**: 人名、人名缩写、姓、名
2. **地址相关**: 地址、街道名、街道号、邮编、国家、美国的州、城市  
3. **证件号码**: 护照号、身份证号、驾照号、银行账号、卡号
4. **时间信息**: 时间戳、出生日期、IP地址、硬件地址

### 3.2 具体标签映射
| 实体类型 | 标签代码 | 示例 |
|---------|---------|------|
| 完整姓名 | FullName | Heather Hatfield |
| 名 | FirstName | Heather |
| 姓 | LastName | Hatfield |
| 完整地址 | Address | 36441 Phillips Underpass Suite 106 |
| 街道号 | StreetNumber | 36441 |
| 街道名 | StreetName | Phillips Underpass |
| 城市 | City | New Daniel |
| 州 | State | MT |
| 邮编 | ZipCode | 49458 |
| 日期 | Date | 05/06/2022 |

### 3.3 扩展类别
根据实际标注过程中遇到的实体类型，可能需要扩展到20种具体标签。

## 4. 技术需求

### 4.1 标注界面要求
- **双栏布局**: 左侧显示标注指令，右侧显示待标注文本
- **实体高亮**: 支持文本选择和高亮显示
- **类别选择**: 便捷的类别选择器
- **进度跟踪**: 显示当前任务进度和完成状态

### 4.2 数据处理要求
- **任务分配**: 支持多标注员并行工作
- **质量控制**: 支持标注结果审核和校验
- **结果统计**: 提供标注进度和质量统计

### 4.3 输出格式要求
```
实体文本: 类别标签
Heather Hatfield: FullName
Heather: FirstName
Hatfield: LastName
```

## 5. 非功能性需求

### 5.1 性能要求
- **响应时间**: 页面加载时间 < 3秒
- **并发支持**: 支持至少10个标注员同时工作
- **数据容量**: 支持2万个任务的稳定运行

### 5.2 易用性要求
- **学习成本**: 新标注员10分钟内掌握操作
- **操作便捷**: 快捷键支持，提高标注效率
- **错误处理**: 友好的错误提示和恢复机制

### 5.3 可靠性要求
- **数据安全**: 标注数据自动保存，防止丢失
- **系统稳定**: 7×24小时稳定运行
- **备份恢复**: 完整的数据备份和恢复机制

## 6. 约束条件

### 6.1 技术约束
- 基于现有Label Studio平台构建
- 保持与现有系统的兼容性
- 支持标准的导入导出格式

### 6.2 业务约束
- 标注质量要求: 准确率 > 95%
- 完成时间: 2万任务在2个月内完成标注
- 人员配置: 5-10名专业标注员

### 7.2 质量验收  
- [ ] 标注准确率 > 95%
- [ ] 系统响应时间满足要求

## 8. 项目计划

### 8.1 开发阶段
1. **需求确认** (1周): 细化需求，确认技术方案
2. **环境搭建** (1周): 配置Label Studio环境
3. **功能开发** (2周): 实现标注模板和工作流
4. **测试验证** (1周): 功能测试和性能测试
5. **部署上线** (1周): 生产环境部署

### 8.2 标注阶段  
1. **标注员培训** (1周): 系统操作和标注规范培训
2. **试点标注** (1周): 小规模试点，优化流程
3. **批量标注** (6周): 全量数据标注
4. **质量验收** (1周): 结果验证和数据交付

## 9. 风险识别

### 9.1 技术风险
- Label Studio定制化复杂度超预期
- 大数据量导致的性能问题
- 实体类别定义存在歧义

### 9.2 业务风险
- 标注质量不达标，需要重新标注
- 标注员流失，影响进度
- OCR预处理质量影响标注效果

### 9.3 风险应对
- 技术预研和原型验证
- 建立标注质量控制机制
- 制定详细的标注规范和培训材料
