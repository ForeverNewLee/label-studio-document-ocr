# 需求分析记录

## [2024-12-19] - 英文票据图片数据标注服务需求分析

**背景**: 用户需要构建一个数据标注服务，处理2万张英文票据图片，进行实体识别和分类标注。

**现有条件**:
- 基于Label Studio的完整项目环境
- 项目已集成OCR和NER模板功能
- 已有预处理的txt文件包含标注指令
- 现有20种实体类别用于分类

**具体需求**:
1. **数据规模**: 2万张英文票据图片
2. **标注任务**: 识别未被[MASK]遮挡的实体并进行类型分类
3. **实体类别**: 包括人名、地址、证件号、时间等20种类型
4. **工作流程**: 基于预处理txt文件进行标注任务分配

**技术分析**:
- Label Studio已支持OCR图片标注模板
- 已有NER文本标注功能
- 需要结合OCR+NER创建复合标注工作流
- 支持批量任务导入和管理

**待明确问题**:
1. 完整的20种实体类别清单
2. 中文界面要求的具体含义
3. txt文件与图片的对应关系
4. [MASK]标记的生成机制和处理方式
5. 期望的输出格式和数据结构

**决策**: 基于示例文件明确了标注任务的具体格式和流程，采用Label Studio的文本标注模板进行实体识别

**实施**: 创建了完整的需求文档，包含：
- 详细的功能需求规格
- 实体类别体系定义  
- 技术实现方案
- 项目计划和风险评估

**结果**: 需求阶段完成，为后续的产品设计和技术实现提供了清晰的指导

**下一步**:
1. 进入产品设计阶段，设计标注界面和用户体验
2. 制定技术架构方案
3. 配置Label Studio标注模板
4. 实施开发和测试
